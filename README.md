# Rana Ebrahim — Portfolio

Personal portfolio for **Rana Ebrahim**, product designer based in Cairo, Egypt. Inspired by the clean, grid-based layout of [lucaslima.design/about](https://www.lucaslima.design/about).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion

## Run locally

```bash
npm install
npm run dev -- --port 3847
```

Open [http://localhost:3847](http://localhost:3847).

## Pages

- `/` — Home (role hero, expertise, selected work)
- `/about` — Bio, career, tech stack
- `/projects` — Selected work
- `/writing` — Design notes

## Customize

Edit content in `src/lib/site.ts` (name, bio, career, projects, links).
