# Rana Ebrahim — Portfolio

Personal portfolio for **Rana Ebrahim**, product designer in Cairo. Built to closely match the structure and studio system of [lucaslima.design](https://www.lucaslima.design/about).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- General Sans (same family as the reference site)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3847](http://localhost:3847).

## Pages

| Route | Content |
| --- | --- |
| `/` | Product Designer hero, expertise grid, selected work |
| `/about` | Bio, collage, career, tech stack |
| `/projects` | Selected work |
| `/writing` | Design notes |

## Customize

Edit `src/lib/site.ts` for name, bio, career, projects, and links. Swap collage photos in `public/media/`.
